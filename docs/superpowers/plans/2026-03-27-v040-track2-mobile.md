- [ ] **Step 2: Fix Cargo.toml — split llama_cpp into platform targets**

In `src-tauri/Cargo.toml`, find:

```toml
llama_cpp = { version = "0.3", features = ["metal"] }
```

Replace with:

```toml
# macOS and iOS: use Metal GPU acceleration
[target.'cfg(any(target_os = "macos", target_os = "ios"))'.dependencies]
llama_cpp = { version = "0.3", features = ["metal"] }

# All other platforms (Linux, Windows, Android): CPU-only inference
[target.'cfg(not(any(target_os = "macos", target_os = "ios")))'.dependencies]
llama_cpp = { version = "0.3" }
```

- [ ] **Step 3: Gate LOCAL_AI_SERVICE initialization**

- [ ] **Step 4: Add frontend platform check**

In `src/services/tauri.ts`, add:

```typescript
import { platform } from '@tauri-apps/plugin-os';

/** Returns true when running on Android or iOS. */
export async function isMobile(): Promise<boolean> {
  if (!isTauriContext()) return false;
  try {
    const p = await platform();
    return p === 'android' || p === 'ios';
  } catch {
    return false;
  }
}
```

Note: `@tauri-apps/plugin-os` may need adding — check with `npm list @tauri-apps/plugin-os`. If absent: `npm install @tauri-apps/plugin-os`.
